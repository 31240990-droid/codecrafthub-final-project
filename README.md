# CodeCraftHub - Personalized Learning Platform for Developers

CodeCraftHub is a personalized learning platform crafted for developers!
This platform helps developers to track their learning journey, manage courses, and upskill effectively.

## Project Features
- Add new courses to learn
- Track learning progress
- User authentication and profile
- Course management (Create, Read, Update, Delete)
- Search and filter courses

## Tech Stack
- Node.js, Express.js, MongoDB, React.js
- Generative AI for documentation and testing
